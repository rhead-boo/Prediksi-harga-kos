INFORMASI SISTEM

Sumber Informasi

Informasi mengenai dataset, metode, dan teknologi yang digunakan dalam sistem prediksi.

01. Dataset

Sistem menggunakan dataset harga kos Madiun dengan 30 data contoh. Variabel yang digunakan meliputi jarak kos, harga, fasilitas AC, dan rating.

02. Metode Machine Learning

Sistem menggunakan algoritma Linear Regression untuk mempelajari hubungan antara jarak, rating, fasilitas AC, dan harga kos. Hasilnya digunakan untuk memperkirakan harga.

03. Teknologi Pengembangan

Python digunakan sebagai bahasa pemrograman, Django sebagai framework web, Scikit-learn untuk Machine Learning, Pandas untuk pengolahan data, Chart.js untuk grafik, dan Groq API untuk penjelasan berbasis AI.

04. Cara Kerja Sistem

Pengguna memasukkan jarak, rating, dan fasilitas AC. Model Machine Learning memproses input tersebut dan menghasilkan estimasi harga kos. Grafik dan AI membantu menjelaskan informasi hasil analisis.

Referensi Teknologi

Dokumentasi resmi teknologi yang digunakan:

  • Dokumentasi Django
  • Dokumentasi Scikit-learn
  • Dokumentasi Pandas
  • Dokumentasi Chart.js
  • Dokumentasi Groq API

Catatan: dataset yang digunakan merupakan data contoh untuk keperluan pengembangan proyek.

ABOUT THE SYSTEM

Mengenal lebih jauh sistem prediksi harga kos di wilayah Madiun berbasis Machine Learning.

Gambaran Umum

Sistem Prediksi Harga Kos Madiun merupakan aplikasi berbasis website yang dikembangkan untuk memperkirakan harga sewa kos berdasarkan beberapa kriteria, yaitu jarak dari pusat kota, rating kos, dan fasilitas AC.

Sistem ini memanfaatkan teknologi Machine Learning dengan algoritma Linear Regression untuk menghasilkan estimasi harga kos berdasarkan data yang digunakan dalam proses pelatihan model.

Tujuan Pengembangan

Tujuan pengembangan sistem ini adalah membantu pengguna memperoleh gambaran estimasi harga kos secara lebih mudah, serta memberikan informasi mengenai data yang digunakan dalam proses prediksi.

Selain itu, sistem ini dikembangkan sebagai penerapan ilmu Machine Learning dan pengembangan aplikasi berbasis web menggunakan framework Django.

Teknologi yang Digunakan

Python

Bahasa pemrograman utama dalam pengembangan sistem.

Django

Framework backend untuk mengelola aplikasi website dan API.

Scikit-learn

Library Python untuk membangun model Machine Learning.

Groq API

Digunakan untuk menghasilkan penjelasan analisis berbasis Artificial Intelligence.

Pandas

Digunakan untuk membaca dan mengolah dataset harga kos.

Chart.js

Digunakan untuk menampilkan visualisasi data dalam bentuk grafik.

Metode Prediksi

Algoritma Linear Regression digunakan untuk mempelajari pola hubungan antara variabel jarak, rating, fasilitas AC, dan harga kos.

Model yang telah dilatih kemudian digunakan untuk menghasilkan estimasi harga berdasarkan input yang diberikan pengguna.

Alur Kerja Sistem

01. Input Data

Pengguna memasukkan jarak kos, rating, dan fasilitas AC.

02. Proses Prediksi

Model Machine Learning memproses data input untuk menghasilkan estimasi harga.

03. Visualisasi

Sistem menampilkan grafik perbandingan harga kos berdasarkan fasilitas AC.

04. Analisis AI

Groq API memberikan penjelasan mengenai hasil prediksi dan grafik.

Batasan Sistem

Hasil prediksi merupakan estimasi berdasarkan dataset yang digunakan, bukan harga pasti atau harga resmi dari pemilik kos.

Ketepatan hasil prediksi bergantung pada kualitas, jumlah, dan karakteristik data yang digunakan untuk melatih model.

Informasi Pengembangan

Sistem ini dikembangkan sebagai proyek pembelajaran pada bidang Teknologi Informasi, dengan menerapkan konsep Machine Learning dan pengembangan aplikasi berbasis web.

Pengembangan sistem mengintegrasikan Python, Django, Scikit-learn, dan Groq API dalam satu aplikasi prediksi harga kos.
